## 步骤 5：编写首个对话脚本

创建 `agent/__init__.py`（空文件）和 `agent/llm.py`：

```python
# agent/llm.py
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

MODEL = os.getenv("OPENAI_MODEL", "deepseek-chat")


def chat(user_message: str, system_prompt: str = "你是一个有帮助的 AI 助手。") -> str:
    response = client.chat.completions.create(
        model=MODEL,
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message},
        ],
    )
    return response.choices[0].message.content
```

修改 `main.py`：

```python
# main.py
from agent.llm import chat

if __name__ == "__main__":
    answer = chat("用一句话解释什么是 AI Agent")
    print(answer)
```

## 核心概念（今日必读）

| 概念 | 说明 |
|------|------|
| System Prompt | 设定 AI 角色和行为边界 |
| User Message | 用户输入 |
| Assistant Message | 模型回复 |
| Chat Completions API | 最常用的对话接口 |

```
用户问题 → messages 数组 → LLM → 文本回复
```

这就是 Agent 的「大脑」—— 后面所有能力都建立在这之上。

## 常见问题

| 问题 | 解决 |
|------|------|
| `AuthenticationError` | 检查 `.env` 中 Key 是否正确 |
| `Connection error` | 检查 `OPENAI_BASE_URL` 和网络 |
| `ModuleNotFoundError` | 确认虚拟环境已激活 |
| 回复是英文 | 在 system prompt 里加「请用中文回答」 |
