## 步骤 1：实现对话记忆

创建 `agent/memory.py`：

```python
# agent/memory.py
from dataclasses import dataclass, field


@dataclass
class ConversationMemory:
    system_prompt: str = "你是一个有帮助的 AI 助手，请用中文回答。"
    messages: list[dict] = field(default_factory=list)

    def add_user(self, content: str) -> None:
        self.messages.append({"role": "user", "content": content})

    def add_assistant(self, content: str) -> None:
        self.messages.append({"role": "assistant", "content": content})

    def to_api_messages(self) -> list[dict]:
        return [{"role": "system", "content": self.system_prompt}] + self.messages

    def clear(self) -> None:
        self.messages.clear()
```

## 步骤 2：升级 LLM 模块

更新 `agent/llm.py`，新增流式和多轮方法：

```python
# agent/llm.py（在原有代码基础上追加）
def chat_with_memory(memory: "ConversationMemory") -> str:
    """非流式，返回完整回复并写入 memory。"""
    response = client.chat.completions.create(
        model=MODEL,
        messages=memory.to_api_messages(),
    )
    reply = response.choices[0].message.content
    memory.add_assistant(reply)
    return reply


def chat_stream(memory: "ConversationMemory"):
    """流式生成，yield 每个 token 片段。"""
    stream = client.chat.completions.create(
        model=MODEL,
        messages=memory.to_api_messages(),
        stream=True,
    )
    full_reply = []
    for chunk in stream:
        delta = chunk.choices[0].delta.content
        if delta:
            full_reply.append(delta)
            yield delta
    memory.add_assistant("".join(full_reply))
```

> 注意：在文件顶部 `from agent.memory import ConversationMemory` 或在函数内延迟导入避免循环引用。

## 步骤 3：实现 CLI 聊天循环

更新 `main.py`：

```python
# main.py
from rich.console import Console
from rich.markdown import Markdown
from agent.memory import ConversationMemory
from agent.llm import chat_stream

console = Console()


def run_chat():
    memory = ConversationMemory()
    console.print("[bold green]Agent Demo 聊天[/]（输入 quit 退出，/clear 清空历史）\n")

    while True:
        user_input = console.input("[bold cyan]你> [/]")
        if user_input.strip().lower() in ("quit", "exit", "q"):
            break
        if user_input.strip() == "/clear":
            memory.clear()
            console.print("[yellow]对话历史已清空[/]\n")
            continue

        memory.add_user(user_input)
        console.print("[bold magenta]AI> [/]", end="")
        for token in chat_stream(memory):
            console.print(token, end="")
        console.print("\n")


if __name__ == "__main__":
    run_chat()
```

## 核心概念

| 概念 | 说明 |
|------|------|
| 短期记忆 | 把历史 messages 塞回 API，模型「看到」之前对话 |
| 流式输出 | `stream=True`，逐 token 返回，体验更好 |
| Token 成本 | 历史越长，每次请求消耗 token 越多 |

```
第1轮: [system, user1] → assistant1
第2轮: [system, user1, assistant1, user2] → assistant2
```

## 常见问题

| 问题 | 解决 |
|------|------|
| 记不住上文 | 检查 `add_assistant` 是否在流式结束后调用 |
| 输出乱码 | Windows 终端设 UTF-8：`chcp 65001` |
| 回复变慢 | 历史太长，可用 `/clear` 或后续做摘要压缩 |
