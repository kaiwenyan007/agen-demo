## Agent 核心循环（今日重点）

```
用户: 现在几点？
  ↓
LLM 判断：需要调 get_current_time 工具
  ↓
程序执行工具，得到 "2026-06-11 14:30:00"
  ↓
把工具结果塞回 messages
  ↓
LLM 生成最终回答："现在是下午 2 点 30 分"
```

## 步骤 1：定义第一个工具

创建 `agent/tools/__init__.py` 和 `agent/tools/datetime_tool.py`：

```python
# agent/tools/datetime_tool.py
from datetime import datetime

TOOL_SCHEMA = {
    "type": "function",
    "function": {
        "name": "get_current_time",
        "description": "获取当前的日期和时间，当用户问现在几点、今天几号时使用",
        "parameters": {
            "type": "object",
            "properties": {},
            "required": [],
        },
    },
}


def get_current_time() -> str:
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
```

---

## 步骤 2：实现工具执行器

创建 `agent/tools/registry.py`：

```python
# agent/tools/registry.py
from agent.tools.datetime_tool import get_current_time, TOOL_SCHEMA as DATETIME_SCHEMA

# 工具名 → 可调用函数
TOOL_FUNCTIONS = {
    "get_current_time": get_current_time,
}

# 注册给 LLM 的 schema 列表
TOOL_SCHEMAS = [DATETIME_SCHEMA]


def execute_tool(name: str, arguments: dict) -> str:
    fn = TOOL_FUNCTIONS.get(name)
    if not fn:
        return f"未知工具: {name}"
    return str(fn(**arguments))
```

## 步骤 3：在 LLM 层支持工具调用

在 `agent/llm.py` 新增：

```python
import json
from agent.tools.registry import TOOL_SCHEMAS, execute_tool


def chat_with_tools(memory: ConversationMemory, max_rounds: int = 5) -> str:
    """支持单轮/多轮工具调用的对话。"""
    for _ in range(max_rounds):
        response = client.chat.completions.create(
            model=MODEL,
            messages=memory.to_api_messages(),
            tools=TOOL_SCHEMAS,
        )
        msg = response.choices[0].message

        # 模型不调工具，直接回复
        if not msg.tool_calls:
            memory.add_assistant(msg.content)
            return msg.content

        # 模型要调工具
        memory.messages.append({
            "role": "assistant",
            "content": msg.content or "",
            "tool_calls": [
                {
                    "id": tc.id,
                    "type": "function",
                    "function": {
                        "name": tc.function.name,
                        "arguments": tc.function.arguments,
                    },
                }
                for tc in msg.tool_calls
            ],
        })

        for tc in msg.tool_calls:
            args = json.loads(tc.function.arguments or "{}")
            result = execute_tool(tc.function.name, args)
            memory.messages.append({
                "role": "tool",
                "tool_call_id": tc.id,
                "content": result,
            })

    return "工具调用轮次超限，请重试。"
```

## 核心概念

| 角色 | 说明 |
|------|------|
| `tools` 参数 | 告诉模型有哪些工具可用 |
| `tool_calls` | 模型返回的调用请求 |
| `role: tool` | 你把工具执行结果回传给模型 |
| `tool_call_id` | 关联请求与结果 |

**关键**：模型只「决定」调什么工具，真正执行的是你的 Python 代码。

## 常见问题

| 问题 | 解决 |
|------|------|
| 模型不调工具 | 检查 `description` 是否清晰；换更强模型 |
| `JSONDecodeError` | `arguments` 可能为空，用 `or "{}"` |
| 无限循环调工具 | 设置 `max_rounds` 上限 |
