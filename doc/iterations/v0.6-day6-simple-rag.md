```

    ↓
Embedding 向量化
    ↓

```

## 步骤 3：实现向量库构建脚本

创建 `agent/rag.py`：

```python
# agent/rag.py
import os
from pathlib import Path

from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma
from langchain_community.document_loaders import DirectoryLoader, TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter

load_dotenv()

PROJECT_ROOT = Path(__file__).resolve().parent.parent
KNOWLEDGE_DIR = PROJECT_ROOT / "knowledge"
CHROMA_DIR = PROJECT_ROOT / ".chroma"

_embeddings = None
_vectorstore = None


def get_embeddings():
    global _embeddings
    if _embeddings is None:
        _embeddings = OpenAIEmbeddings(
            api_key=os.getenv("OPENAI_API_KEY"),
            base_url=os.getenv("OPENAI_BASE_URL"),
            model=os.getenv("EMBEDDING_MODEL", "text-embedding-3-small"),
        )
    return _embeddings


def build_vectorstore(force_rebuild: bool = False) -> Chroma:
    global _vectorstore
    if _vectorstore is not None and not force_rebuild:
        return _vectorstore

    if CHROMA_DIR.exists() and not force_rebuild:
        _vectorstore = Chroma(
            persist_directory=str(CHROMA_DIR),
            embedding_function=get_embeddings(),
        )
        return _vectorstore

    loader = DirectoryLoader(
        str(KNOWLEDGE_DIR),
        glob="**/*.md",
        loader_cls=TextLoader,
        loader_kwargs={"encoding": "utf-8"},
    )
    docs = loader.load()
    splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
    chunks = splitter.split_documents(docs)

    _vectorstore = Chroma.from_documents(
        chunks,
        get_embeddings(),
        persist_directory=str(CHROMA_DIR),
    )
    return _vectorstore


def search_knowledge(query: str, k: int = 3) -> str:
    vs = build_vectorstore()
    results = vs.similarity_search(query, k=k)
    if not results:
        return "知识库中未找到相关内容。"
    parts = []
    for i, doc in enumerate(results, 1):
        source = doc.metadata.get("source", "unknown")
        parts.append(f"[片段{i} | {source}]\n{doc.page_content}")
    return "\n\n".join(parts)
```

## 步骤 4：把 RAG 注册为 LangChain 工具

在 `agent/langchain_agent.py` 中追加：

```python
from agent.rag import search_knowledge, build_vectorstore

@tool
def query_knowledge_base(question: str) -> str:
    """从项目知识库检索与问题相关的文档片段。用户问项目功能、概念、FAQ 时优先使用。"""
    return search_knowledge(question)

# 更新 TOOLS 列表
TOOLS = [get_current_time, read_file, list_files, query_knowledge_base]
```

在 `main.py` 启动时预热向量库：

```python
from agent.rag import build_vectorstore

if __name__ == "__main__":
    print("正在加载知识库...")
    build_vectorstore()
    run_chat()
```

## 核心概念

| 概念 | 说明 |
|------|------|
| Chunking | 长文档切成小块，检索更精准 |
| Embedding | 文本 → 向量，用于语义相似度搜索 |
| Top-K | 取最相关的 K 个片段 |
| 幻觉降低 | 回答有据可查，附带来源片段 |

## 常见问题

| 问题 | 解决 |
|------|------|
| Embedding API 报错 | 换支持 embedding 的 base_url，或用本地模型 |
| 检索结果不相关 | 调小 `chunk_size`；增加文档；优化问题表述 |
| 首次启动慢 | 正常现象，后续走持久化 `.chroma/` |
