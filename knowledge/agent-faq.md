# Agent 常见问题

## 什么是 ReAct？

ReAct 是推理（Reasoning）与行动（Acting）结合的 Agent 模式，模型交替进行思考和工具调用，直到完成任务。

## 什么是 RAG？

RAG（检索增强生成）先从知识库检索相关内容，再让 LLM 基于检索结果回答，减少幻觉，适合基于文档的问答场景。

## RAG 和直接读文件有什么区别？

- **读文件**：每次把整份文件内容塞进上下文，文件大时浪费 token，也无法跨文档检索。
- **RAG**：把文档切成小块并向量化，按问题语义检索最相关的片段，更精准、更省 token。

## 这个项目有哪些功能？

- 多轮对话
- 工具调用（时间、计算、文件）
- RAG 知识库问答
